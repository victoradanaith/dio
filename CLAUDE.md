# Dio SSIS Works

Tracks how Dio (SSIS P1, AY 2026–2027, Thai-Thai class + Mandarin Pinyin class) is doing at school.

## Learning tracker (`tracker/`), built on the Marble os-taxonomy
The core is the "micro-topics" and prerequisite graph from https://github.com/withmarbleapp/os-taxonomy (a copy pinned in `tracker/taxonomy/`; see `SOURCE.txt`).

| File | Role |
|---|---|
| `tracker/taxonomy/` | Marble data (topics, dependencies, clusters). **Don't edit.** To update, re-clone and copy the same files over. |
| `tracker/extensions.json` | Thai and Mandarin topics that Marble doesn't have. Same format; IDs start with `x_th_` / `x_zh_`. |
| `tracker/ssis-map.json` | Maps SSIS units (from teachers' LINE posts and exam pointers) to topic IDs. |
| `tracker/progress.json` | Dio's status per topic plus the evidence log. **This is the only file that holds Dio's progress.** |
| `tracker/dio.py` | CLI: `find`, `show`, `seed`, `log`, `next`, `build` |
| `tracker/dashboard.html` | Generated by `build` from `dashboard.template.html`. Don't edit it by hand. |
| `tracker/graph.html` | 3D graph of every topic (like withmarble.com/curriculum), also generated by `build` (from `graph.template.html`). Colours show Dio's status, plus "likely passed" inferred from prerequisites (`inf_prereq`) and from age (`inf_age`: English/Maths topics for age ≤ 6). See `likely_passed()` in dio.py. Open it via the `tracker` preview server (`.claude/launch.json`, port 8791). |

Statuses: `not_started` → `introduced` (taught at school) → `practising` → `secure` (meets the topic's `evidence` criteria) / `review` (slipped back).

### Workflow when new information comes in
1. **New content from school** (LINE, exam pointers): add a unit to `ssis-map.json`. Use `python3 -I tracker/dio.py find <keyword>` to pick topic IDs. If no topic fits (Thai, Chinese, SSIS-specific), add one to `extensions.json` with its prerequisites.
2. **Results or observations** (marked work, test scores, practice at home): `python3 -I tracker/dio.py log <topicId|unitId> <status> --source "..." --note "..." --date YYYY-MM-DD`. Judge the status against the topic's `evidence`; one score is not enough to call something secure.
3. `python3 -I tracker/dio.py seed` (picks up newly mapped topics) → `build` → `next` to see which prerequisites to check and what's ready next.

SSIS uses the Singapore curriculum, but Marble aligns to UK/US/AU/Ontario/NCERT. A mapping is "closest fit", not an official one.

Report cards: save the photo in `school-reports/` and add an entry to `reports` in `progress.json` (subject marks, competencies, comment). The report card gives only one mark per subject. If the mark is high, the mapped topics go to `practising` (not `secure`), and the foundations they rely on can be inferred as `secure`; note in the log that it was inferred.

## Git / GitHub
The repo is **public**, so personal files are kept out by `.gitignore`: `school-reports/`, `exam-materials/`, `progress.json`, the generated `dashboard.html`/`graph.html` (they embed the progress data), and `Dio_CA1_Revision_Guide.md` (it comes from the private parent group). Never `git add -f` these files, and don't put scores or personal details in committed files.
- `Dio_CA1_Revision_Guide.md`: Term 1 CA1 content (as of Sep 2026)
- `exam-materials/`: English mock exam + answer key
- SSIS P1 LINE group: read-only. See the global CLAUDE.md for how to read it (D1 via wrangler). **Never send anything to this group.**
